# Suggested Improvements

This directory is the public proposal area for PXOL external validators.

Use `<name-or-handle>_<topic>_<number>/`.

Example: `smith_memory_retention_001/`

Every proposal should include:
- `README.md`
- one or more proposed code files where applicable
- evidence or findings
- test results where available

Copy `_TEMPLATE/` to start.

Material here is external proposed work. It is not PXOL core merely because it appears in this directory.
