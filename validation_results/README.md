# Validation Results and Sign-off

Each completed external validation should have its own folder.

Use a unique identifier such as `PXOL-EV-2026-0001`.

```
validation_results/
  PXOL-EV-2026-0001/
    validator_signoff.md
    results.csv
    environment.txt
    raw_outputs/
    failures/
```

## Required sign-off material

- validator name or ID
- organisation if supplied
- PXOL version
- commit or package checksum
- Python version
- operating system
- hardware
- protocol outcomes
- protocol deviations
- overall conclusion
- declaration
- date

Use only: Pass, Fail, Partial, Inconclusive.

Completing the protocol does not require a positive result.
