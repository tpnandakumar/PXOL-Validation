# START HERE: PXOL External Validation

This repository is the **public validation interface**, not the private PXOL source repository.

## What to use

### 1. Validation protocol
Open **PROTOCOL.md** to see the fixed tests and reporting rules.

### 2. Results workbook
Use **PXOL_1.0_External_Validation_Workbook.csv** to record results.

### 3. Runnable PXOL validator

**Windows download:** https://github.com/tpnandakumar/PXOL-Validation/releases/download/v1.0-validator/PXOL_Validator.exe

Download and run `PXOL_Validator.exe`.

**Do not attempt to validate PXOL from README.md alone.**

The private development repository is not exposed here.

## Validation workflow

1. Obtain the PXOL validator build.
2. Run the fixed protocol.
3. Preserve raw outputs and environment details.
4. Complete the results workbook.
5. Choose either:
   - **Suggested Improvement**
   - **Validation Sign-off**

## Current repository contents

This public repository contains the protocol, reporting templates, contribution route and sign-off route.

The runnable validator build is a separate deliverable because the PXOL development source remains private.
